# Text and Number Tools

## UpStartInterns – Python Programming Internship

**Task 01: Text and Number Tools**

## 📌 Project Description

Text and Number Tools is a beginner-friendly Python project that performs basic text analysis and number checking.

The program accepts a sentence and a number from the user, analyzes the text, reverses the sentence, and checks whether the given number is prime.

## 🎯 Objectives

- Calculate the total number of words in a sentence.
- Find the longest word in a sentence.
- Reverse a given sentence.
- Check whether a number is prime or not.
- Understand Python functions, loops, conditions, and string operations.

## 🛠️ Technologies Used

- Python 3
- Visual Studio Code

## ⚙️ Features

1. **Word Count:** Counts the total words in the entered sentence.
2. **Longest Word:** Identifies the word with the maximum number of characters.
3. **Sentence Reversal:** Reverses the entire sentence character by character.
4. **Prime Number Checker:** Determines whether the entered number is prime or not.

## 🚀 How to Run the Project

### Step 1: Install Python

Download and install Python 3 from https://www.python.org/

### Step 2: Open the Project

Open the project folder in Visual Studio Code.

Open the VS Code terminal and execute:

